In Saturon, the main entry point for object-oriented workflows is the `Color` class, exported directly from the primary package.

```ts
import { Color } from "saturon";
```

For applications with strict bundle-size requirements or functional programming paradigms, Saturon also offers standalone, tree-shakable utilities. These pure functions can be imported individually from dedicated subpaths to ensure you only bundle the exact features you use.
