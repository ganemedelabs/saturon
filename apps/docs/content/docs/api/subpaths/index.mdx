Saturon provides its core features as standalone, tree-shakable utility subpaths. If you prefer a functional programming paradigm or need strict bundle-size optimizations, you can import these pure functions directly instead of using the object-oriented `Color` class.

Every method available on the `Color` class is powered by these underlying standalone functions.
